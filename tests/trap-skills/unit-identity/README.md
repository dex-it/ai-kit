## Тип единиц и дубли (шаг 0)

Содержание - конвенции корпуса (ключ тождества, схема номеров, снятие с пометкой), видимые из соседних
файлов: кейсы на корпусе, где они соблюдаются. Решение принято до прогонов.

Дубли:
- «Номера» (7 единиц: сквозняк, номер откуда придётся, конфликт счётчика, счёт по памяти, снятый номер,
  откат `feature`, две ветки на счётчик) = `project-docs-map` п.5-п.6 (устройство `.req_counter`,
  выдача, восстановление, недостижимость, откат, конфликт при слиянии) плюс процедура счётчика в телах
  составителей. Дом - там; здесь остаётся схема блока (на неё указывает `docs-layout`) и указатель.
  Конфликт счётчика = `merge-conflict-resolution` (#308) - дом `project-docs-map` п.6.
- «Правку вносят молча, род изменения не объявляют» = `decision-log` «Род изменения не записан»: дом
  здесь.
