## Открыто

- «Метод не наблюдает результат»: засев FR-2010 (журнал проверяется одним примером) не взят ни в одном
  наборе; применение вне ключа у `s` есть, у контроля не мерилось. Засев, возможно, не вынуждает
  дефект; пункт оставлен названием до кейса, где метод явно не видит результат.
- FR-2008 (модальность «может», нет случая): `s` и `v` называют только метод и основание. Контроль судил
  другой судья и засчитал ту же формулировку («проверки нет»); сравнение по якорям - не регресс, а
  разошедшаяся калибровка. Отдельного кейса на форму нет.
