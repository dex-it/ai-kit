## Открыто

- Пункт метода на ступени «исход» тянет находки о методе и туда, где ключ дефекта метода не засевал. В
  `r1-g2` из трёх таких находок верна одна (FR-2007: одним примером процентиль не наблюдается), две мягкие
  ложные (FR-2005 «часть без метода» при названном методе; FR-2014 - метод для подменённого требования);
  в `r1-g1` обе верны (NFR-2003, FR-2015). В c0 `c0-g1` добавил словесное «мера BR-1002 эффект правила не
  наблюдает» - по корпусу спорно, правок нет. Ключ эти места не судит; кейса на избыточные находки о
  методе нет.
- FR-2008 (модальность «может», нет случая): `s`, `v`, `f`, `g` называют только метод и основание. Контроль
  судил другой судья и засчитал ту же формулировку («проверки нет»); сравнение по якорям - не регресс, а
  разошедшаяся калибровка. Отдельного кейса на форму нет.
