# Безопасность общего стенда

Пункт - ситуация, которую исполнитель не заподозрит.

- `kubectl exec` с запуском команд, меняющих файлы, env или процессы внутри контейнера.
- Расследователь меняет статус Jira, пишет в MR или дёргает пайплайн во время read-only анализа.
- Тяжёлый запрос, полный скан, MONITOR, EXPLAIN ANALYZE с записью "просто посмотреть" на нагруженном стенде.
