Решения:
- Запрос уходит на сервер через `getOrders(q)` спустя 250 мс после последнего ввода. Ответ на устаревший запрос отбрасывается, поэтому порядок ответов не перепутает результаты. Пока идёт поиск, прежний список остаётся на экране.

- Новый тест вводит «Чайник», проверяет, что список сузился, очищает поле и ждёт возврата полного списка. Затем вводит «zzz» и ждёт «Ничего не найдено».
