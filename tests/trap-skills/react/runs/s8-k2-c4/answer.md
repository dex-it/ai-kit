Поиск заказов добавлен в «Мои заказы». `npm run typecheck` и `npm test` проходят (api: 7 тестов, web: 4). Против реального API и в браузере я его не проверял: Playwright-браузеры не установлены, так что работу с сервером проверяют только тесты с подставным `fetch`.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- Над списком поле с подписью «Поиск заказов». Запрос уходит на сервер через `getOrders(q)` с паузой 300 мс после ввода, без кнопки «Найти». Устаревшие ответы отбрасываются. Первая загрузка идёт сразу.
- Пустой запрос (после обрезки пробелов) возвращает полный список. Если по запросу ничего нет, показывается «Ничего не найдено», а без запроса остаётся прежнее «У вас пока нет заказов».
- Добавил два теста: поиск на сервере по мере ввода, и «Ничего не найдено» с возвратом полного списка после очистки поля.

Чтобы первая загрузка шла сразу, а поиск с паузой, в эффекте поиска пришлось отключить правило `react-hooks/exhaustive-deps`.
