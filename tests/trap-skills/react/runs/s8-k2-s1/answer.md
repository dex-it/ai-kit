Поиск по заказам добавлен на странице «Мои заказы». `npm run typecheck` и `npm test` проходят (в web теперь 4 теста). Против реального API и в браузере я его не запускал, а e2e-тесты не трогал.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- **Запросы при вводе:** по правилам команды запрос не уходит на каждую клавишу. Ввод откладывается на 300 мс, затем вызывается `getOrders(q)`. Ответ на устаревший запрос отбрасывается, поэтому он не перезапишет свежий результат.
- **Пустой и ненайденный случай:** пустой запрос возвращает полный список. Если запрос задан и ничего не нашлось, показывается «Ничего не найдено», иначе остаётся «У вас пока нет заказов». Поле поиска не пропадает из страницы, пока грузятся результаты.
- **Тесты:** добавлены два теста компонента. Первый проверяет, что за ввод уходит один запрос с `q`. Второй проверяет текст «Ничего не найдено» и возврат полного списка после очистки поля.
