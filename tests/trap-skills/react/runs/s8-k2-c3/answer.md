Поиск по заказам добавлен на странице «Мои заказы». `npm run typecheck` и `npm test` проходят (в web 4 теста, из них 2 новых). Проверка против реального API не делалась: сервер я не запускал, и Playwright-браузеров нет.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- **Ввод:** поле «Поиск заказов» отправляет запрос на сервер через `getOrders(q)` с задержкой 300 мс. Ответы от уже неактуальных запросов отбрасываются. Начальная загрузка идёт без задержки, пустой запрос возвращает полный список.
- **Пустой результат:** при непустом запросе показывается «Ничего не найдено», при пустом по-прежнему «У вас пока нет заказов». Поле остаётся на месте во время загрузки.
- **Тесты:** первый проверяет, что ввод уходит на сервер с `?q=` и список сужается. Второй проверяет сообщение «Ничего не найдено» и возврат полного списка после очистки поля.

В хуке эффекта оставлен комментарий `eslint-disable` для `exhaustive-deps`. Я не проверял, есть ли в проекте eslint, поэтому комментарий может оказаться лишним.
