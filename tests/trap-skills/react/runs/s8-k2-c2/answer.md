Поиск заказов добавлен на странице «Мои заказы». `npm run typecheck` и `npm test` проходят. Проверял только тестами на мок-`fetch`: с реальным API, запущенным вместе с web, поиск не прогонял.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- Над списком добавлено поле с подписью «Поиск заказов». Запрос уходит на сервер через `getOrders(q)` с задержкой 300 мс после ввода, без кнопки «Найти». Пустой запрос возвращает полный список сразу, без задержки. Ответы на устаревшие запросы отбрасываются.
- Если по непустому запросу ничего нет, показывается «Ничего не найдено». «У вас пока нет заказов» остаётся только для пустого запроса.
- Новый тест вводит запрос, проверяет URL запроса и результат, затем «Ничего не найдено» и возврат к полному списку после очистки поля.
