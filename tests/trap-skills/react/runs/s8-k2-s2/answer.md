Поиск по заказам готов. `tsc --noEmit` и `vitest` в `web` проходят: 3 теста, включая новый. Корневые `npm run typecheck` и `npm test` я не запускал. Против реального API вручную не проверял — только тест с подменой `fetch`.

Изменены:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- **Запросы при вводе:** поле «Поиск заказов» запрашивает сервер не на каждое нажатие, а через 300 мс после паузы в наборе. Запрос идёт через `getOrders(q)`. Ответ на устаревший запрос отбрасывается, поэтому он не перезапишет свежий.
- **Список и пустые состояния:** пустой запрос возвращает полный список. Пока идёт повторный поиск, прежний список остаётся на экране, а поле не пропадает. «Ничего не найдено» показывается при непустом запросе без результатов. Без запроса остаётся прежнее «У вас пока нет заказов».
- **Тест:** новый тест на компонент с fake timers проверяет, что набор «zzz» даёт один запрос `/api/orders?q=zzz`. Он же проверяет текст «Ничего не найдено» и возврат к `/api/orders` после очистки поля.
