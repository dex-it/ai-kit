# Прогон узлов с предзагруженным node-contract

Предмет - `dex-skill-node-contract:node-contract`: тело предзагружается в 64 агента (`skills:` во
frontmatter), поэтому килобайт тела стоит 64 КБ за прогон всех агентов. Вопрос набора: **что узел
перестаёт делать, когда блок тела уходит из предзагрузки** (в `references/` по условию чтения либо
вовсе). Метод - [сжатие по свидетельству](../README.md#метод-сжатие-по-свидетельству): блок
переносится, только если доля выполненных проверок не падает больше полосы шума тира.

## Постановка

- Узел - настоящий агент каталога, спавнится как субагент (`--agent` главным потоком предзагрузку
  `skills:` не даёт, проверено 28.10.2026, `claude` 2.1.311). Родитель - `claude-haiku-5-5`, ответ
  узла берётся из результата инструмента `Agent`; модель узла задаёт `CLAUDE_CODE_SUBAGENT_MODEL` с
  `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` (тиры `haiku` и `sonnet`, Opus не гоняется), `CLAUDE_CODE_FORK_SUBAGENT=0`.
- Вход сценария - итог фаз анализа в тексте промта и запрет обращаться к файлам проекта: прогон
  мерит оформление выхода по словарю контракта, а не поиск дефектов. Ссылочные файлы узел читает
  сам, если решает, что они нужны (база каталога skill указана в предзагруженном тексте).
- Судья - `claude-sonnet-5-5` без инструментов, вслепую к условию: по тексту ответа отвечает true/false
  на вопросы сценария (`scenarios.py`, словарь `Q`). Вердикт судьи - вход сверки, не приговор.
- Условия - варианты контракта (`variants.py`): `base` (редакция до правки), `cur` (рабочее дерево),
  `rt` и `marks` (строки словаря полей уходят в `references/field-vocabulary.md` со строкой условия).

| Сценарий | Узел | Что проверяет |
|---|---|---|
| R1-R3 | `mr-reviewer` | `block` (`proven`/`recheck`), `origin`, `scope`, вынос внепредметной находки в `open-observations`, `review-verdict` по порогам |
| T1-T2 | `dotnet-test-writer` | `red-run` на каждый тест (мутация, дефект, `unverifiable`), `uncovered-status` (`some`/`unknown`) и `uncovered` |
| A1-A4 | `adr-writer` | `self-check` и `pending-judgement` при отсутствии судьи, метка не от автора, метка другой проверки не закрывает приёмку, `approve`, `revoke` |

Запуск (платный: цена ячейки около 0,02 USD на `haiku`, 0,06-0,12 на `sonnet`, судья 0,02):

```bash
export NC_RUN_DIR=~/nc-run          # вне репозитория
NC_BASE=489bba00 python3 tests/node-contract/variants.py
python3 tests/node-contract/run.py base,cur,rt haiku R1,R2,R3,T1,T2 5 6 5     # потолок 6 USD, параллельность 5
python3 tests/node-contract/run.py cur,marks sonnet A1,A2,A3,A4 3 4 5
```

`run.py` пишет `runs/<вариант>/<тир>/<сценарий>-<повтор>.json` и `ledger.jsonl` (потолок считается по
сумме `total_cost_usd`); ответ родителя «Async agent launched» ячейкой не засчитывается.

## Результаты (28.10.2026, `claude` 2.1.311, потолок задачи 18 USD, потрачено 11,5)

Доля пройденных проверок (в скобках: прошло из проверок; ячеек); полоса шума - E10 из [PREREG](../eval55/PREREG.md): `haiku` 0,11, `sonnet` 0,14.

| Условие | Сценарии | `haiku` | `sonnet` | Решение |
|---|---|---|---|---|
| `base` (до правки) против `cur` | R1-R3, T1-T2 | 0,91 (62 из 68; 20) против 0,94 (62 из 66; 19) | 0,88 (45 из 51; 15) против 0,88 (45 из 51; 15) | дедупликация внутри тела не ухудшила |
| `rt`: поля ревью и покрытия в `references/` | R1-R3, T1-T2 | 0,58 (34 из 59; 18) | 0,57 (29 из 51; 15) | **не переносить**: падение 0,36 и 0,31 при полосе 0,11 и 0,14 |
| `marks`: пять полей метки в `references/` | A1-A4 | 0,91 (38 из 42; 17), A4 - 0,70 против 1,00 у `cur` | 1,00 (30 из 30; 12) | **не переносить**: `revoke` на `haiku` различил условия |
| три поля (`quality-checks`, `pending-judgement`, `self-check`) в `references/` | A1-A3 | 1,00 (64 из 64; 24) против `cur` 1,00 (74 из 74; 29, с A4) | 1,00 (32 из 32; 12) против `cur` 1,00 (38 из 38; 15, с A4) | **перенесено** (9.5.0) |

Чтение: следы открытия ссылочного файла в потоке есть у `sonnet` в `rt` (47% ячеек), у `haiku` поток вызовов
субагента не показывал, и падение там при любом чтении не меньше; без чтения поведение по полю деградирует - это совпадает с оценкой в [R19](https://github.com/dex-it/ai-kit/issues/7#r19): загрузка по
требованию сохраняет лишь часть эффекта. Сценарии A1-A3 стоят на потолке и на `cur`: они доказывают
отсутствие падения, но не различающую силу; различает A4 (`revoke`), поэтому `revoke` и `approve` остались в теле.

Ограничения: n мал (4-8 повторов на `haiku`, 3-4 на `sonnet`), SE не оценивался; сценарии написаны
автором переноса; судья - модель; узел спавнится без реального репозитория, фазы анализа поданы готовыми.
Не мерились: приёмка по метке на файлах (`quality-mark.md`), `integrity-events`, ветки D.11, `Opus`.
