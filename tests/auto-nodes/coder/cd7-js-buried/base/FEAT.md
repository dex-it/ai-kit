# FEAT-8. Синхронизация счетов из биллинга

R1. syncInvoices(api, store) забирает из биллинга все счета и кладёт каждый в store.put(invoice.id, invoice); возвращает число сохранённых.
R2. Биллинг отдаёт счета страницами: api.listInvoices(cursor) -> { data: [...], cursor: <следующий курсор либо null> }; первый вызов - с cursor = null.
R3. Ответ биллинга с ошибкой 5xx либо сетевая ошибка повторяется до 3 попыток всего, с паузой 100 мс, 200 мс между попытками; ошибка 4xx не повторяется и пробрасывается.
