# FEAT-11. Уведомление поставщиков о заказе

R1. notifySuppliers(suppliers, mailer, order) отправляет каждому поставщику письмо вызовом mailer.send(supplier.email, { order: order.number }) и возвращает число отправленных.
R2. Почтовый шлюз временно недоступен (ответ 5xx либо обрыв соединения ECONNRESET, ETIMEDOUT) - письмо отправляется ещё раз, всего не больше 3 раз, с паузой 100 мс перед вторым и 200 мс перед третьим; ответ 4xx пробрасывается сразу.
