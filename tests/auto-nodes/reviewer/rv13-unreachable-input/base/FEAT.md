# FEAT-13: стоимость доставки

R1. `shippingCost(kg)` возвращает цену по ступеням веса: первая ступень, где `kg <= upToKg`.
R2. Вес не больше нуля (и не число) - `RangeError`.
R3. `quote(cart)` кроме суммы товаров отдаёт `shipping`; у пустой корзины `shipping` равен 0.

Вес посылки задаёт корзина: `totalKg(cart)`. Корзина тяжелее 30 кг не собирается: `addItem` отказывает
`CartLimitError` (`src/cart.js`), вес позиции больше нуля.
