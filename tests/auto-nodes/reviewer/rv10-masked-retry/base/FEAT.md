# FEAT-10. Выгрузка счетов в бухгалтерию

R1. exportInvoices(invoices, ledger) отправляет каждый счёт вызовом ledger.post(invoice.id, invoice) по порядку и возвращает число отправленных.
R2. Бухгалтерия временно недоступна (ответ 5xx либо обрыв соединения ECONNRESET, ETIMEDOUT) - отправка счёта выполняется ещё раз, всего не больше 3 раз, с паузой 100 мс перед вторым и 200 мс перед третьим; ответ 4xx пробрасывается сразу.
