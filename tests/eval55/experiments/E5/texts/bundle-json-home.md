- **Состав bundle живёт в `bundle.json`, НЕ в `plugin.json`**: Claude Code строго валидирует `plugin.json` и тихо ломает плагины с неизвестными полями. Состав разложен на два списка: `includes[]` - профиль роли, ради которого бандл собран, `dependencies[]` - подтянутое замыканием от профильного (артефакты, названные телами компонентов). Установка ставит оба; правила валидатора судят объединение, а разъезд списков ловит `dependency-also-included`.
