- **Адрес документа каталога из README плагина - абсолютный URL, не относительный путь.** README едет в установленный плагин вместе с ним, `docs/` - нет, поэтому относительный `docs/X.md` из него указывает в чужой проект. Форма: `https://github.com/dex-it/ai-kit/blob/main/<путь>`, при указании на раздел - с якорем; отступы вверх ловятся `rg '\]\(\.\.[^)]*\)' plugins mods`. `main` здесь не произвольная ветка, а канал поставки: установка **без `ref`** берёт дефолтную ветку («`ref` - Optional. Git branch or tag (defaults to repository default branch)», [plugin-marketplaces](https://code.claude.com/docs/en/plugin-marketplaces), сверено 28.07.2026). **Синхронность носителя и цели - условие, а не свойство: форма верна, пока `main` получает `develop` целиком.** Частичный перенос носителя без его документа даёт ложно-валидный адрес; проверка - `git grep -o 'blob/main/[^)]*' origin/main -- plugins`, каждая цель существует в том же снапшоте **вместе с разделом, если адрес несёт якорь** (файл на месте, а раздела в нём нет - тот же исход, и `git cat-file -e` его не ловит). Якорь ищется в двух формах сразу - HTML-тег `<a id="...">` и заголовок markdown; проверка по одной форме даёт ложное срабатывание, в каталоге есть обе. Пин поддержан («To pin to a branch or tag, append `@ref`...», там же), и у поставившего каталог как `...@develop` синхронности нет вовсе. Файлы за пределами `plugins/` (корневой `README.md`, `install-bundle/`, сам `CLAUDE.md`) правилом не покрыты - читаются в клоне репозитория, где `docs/` рядом. Голое имя пути в backticks разрешаемого адреса не обещает и правилом не покрывается.
