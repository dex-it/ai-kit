# /do

Выполнить задачу пользователя способом, который окупается: одной сессией или пакетом исполнителей.

## Goal

1. Аргумент - каталог с `PLAN.md` -> вызови `Skill` `dex-skill-orchestration-executor:orchestration-executor` на нём (исполнение либо возобновление по журналу).
2. Иначе вызови `Skill` `dex-skill-orchestration-planner:orchestration-planner`: аргумент - задача, предмет и лимиты. Исход плана:
   - `solo` без пакета (ответ в чате) -> выполни задачу по карточке запуска;
   - пакет, `scheme: solo` -> исполнитель на пакете;
   - пакет, `scheme: orchestrate` -> исполнитель на пакете после согласия пользователя на план; отказ -> стоп, путь пакета в ответе.

## Output

Результат задачи. При пакете - его путь, схема с расчётом против одной сессии, после исполнения - `reports/FINAL.md`.
