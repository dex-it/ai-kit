# /do

Выполнить задачу пользователя режимом не выше нужного. Режим наращивается только по наблюдённому
признаку: малая задача не платит системе ничего.

## Goal

Выбери режим по задаче, назови его и признак одной строкой, выполни.

| Режим | Признак | Исполнение |
|---|---|---|
| L0 одна сессия | умолчание: цепочка зависимых шагов, всё влезает в контекст, машинной проверки нет | сам, без раздачи |
| L1 сам и исполнители | выигрыш назван: параллельность нужна по времени, независимость нужна по смыслу (проверка чужого вывода, недоверенное содержимое), категория куска выше твоей модели; одной независимости кусков мало | `Skill` `dex-skill-subagent-dispatch:subagent-dispatch`, затем раздача по его пунктам |
| L2 пилот и раздача | десятки однотипных кусков **и** машинная проверка, равная приёмке | пилот 2-3 куска на дешёвом тире, замер цены и доли прошедших, затем сценарий `Workflow` с повтором выше (раздел «Десятки однотипных кусков» того же скилла); без такой проверки L2 нет |
| L3 план и цели | работа не помещается в контекст одной сессии | см. «L3» ниже |

Сомневаешься между режимами - низший. Расчёт цены по таблице не заменяет пилот: она ошибалась в
6-27 раз.

## L3

Схема, не поставка: готового скрипта в каталоге нет. L3 включай только когда L0 не вмещает работу: на
работе, вмещающейся в контекст, волна целей `/auto` против одной сессии вышла в 20 раз дороже и в 17
раз дольше при том же исходе (замер 13.10.2026, одна фикстура). План сильной моделью: граф целей, у
каждой цель, критерий «готово» в проверяемой форме и граница; волны по зависимостям. Исполнитель цели -
`/auto` (`dex-auto`), параллельно процессами `claude -p` в одном репозитории; зависимой цели ветка
`auto/<TASK>` заводится заранее от интеграционной ветки; ветки волны вливаются, конфликты общих файлов
разрешает одна сессия, после волны полный прогон тестов. Цель в `blocked` ждёт ответа оператора и
возобновляется `/auto <TASK> продолжить`. Цена цели 2-6 $ и 7-20 минут; только код.

## Output

Режим и признак одной строкой, результат задачи; при L1 и выше - число исполнителей и что принято по
проверке, а что нет.
