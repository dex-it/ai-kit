# Поля метки и самопроверки

Материал `node-contract` по требованию; условие чтения - таблица «Материалы по требованию» в
`SKILL.md`. Поля сверяются по смыслу, не по имени (правило словаря полей в `SKILL.md`).

| Поле | Смысл | Синонимы источника |
|---|---|---|
| `quality-checks` | артефакты, уже **осуждённые судьёй** в этом флоу (сквозное, п.7). **Носитель метки - файл рядом с артефактом**, поле выхода - копия-индекс: одно оно до следующего узла не доживает (носители и старшинство - `references/quality-mark.md`) | список `{artifact, check, verdict, revision}`; ключ - тип, **проверка** и путь, поэтому метка одного типа проверку другого не закрывает. `revision` - номер плюс указатель на неизменяемую версию или снимок (`references/revision.md`): без него правленный мимо конвейера текст от судимого не отличить |
| `pending-judgement` | ожидаемая, но не состоявшаяся проверка, объявленная **автором** до суда: `{check, reason, by: author}`. Не вердикт, порога не даёт (`references/quality-mark.md`). **Носитель - выход узла**, в шапку не переносится | «оракула типа нет», «судья в маршруте не назначен»; в `verdict` не переносится |
| `self-check` | самоконтроль автора перед сдачей: какой оракул прогнан по своему артефакту и что по его находкам починено. **Носитель - выход узла**, разделом артефакта не становится | `{check, что устранено}`; не проверка для приёмника, судью не заменяет (п.7) |
