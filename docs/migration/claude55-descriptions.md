## 4. Рекомендации по формулировкам (по данным выше)

1. **Бюджет считается всей записью, а не одной.** Кап 1 536 знаков каталог не достигает (максимум 500), поэтому длину одной записи резать ради капа незачем; вся экономия - суммарная (SKILL_FRAMEWORK, «Бюджет листинга»). Первый рычаг автора каталога не меняется: срезать точки входа у источника.
2. **Первая фраза несёт роль.** В реальных парах выше различие лежит в первых словах («Первичное ревью», «Ре-ревью», «Оракул», «Норматив жанра», «Узел ... вызывается скриптом»); хвост триггеров у соседей почти всегда общий. Пара, разведённая только хвостом, - кандидат на правку: роль (пишет / судит / исполняет / хранит норму) ставится в начало, а не в конец.
3. **Хвост триггеров соседа не копируется.** Две из семи реальных пар (и ещё `test-automator` частично) имеют общий хвост почти дословно (skill и его агент-исполнитель, оркестратор и его исполнитель). Когда артефакт вызывается другим артефактом по имени, его `description` описывает вызов (вход, выход), а не пользовательский запрос.
4. **Без `<` и `>` в `description`.** Документация: клиент показывает их как `&lt;` и `&gt;`. В семи описаниях есть `>` (`->`, `>=`, `> 0`); влияет ли это на текст, который видит модель, не задокументировано, поэтому существующие описания не правились, а новые пишутся без угловых скобок (`argument-hint` для заполнителей).
5. **Витрина и поле срабатывания - два текста.** Витрина по телу и без слов-триггеров, поле срабатывания - роль плюс «Активируется при» (SKILL_FRAMEWORK). Скопировать одно в другое - ошибка в обе стороны; из двух нарушений на 201 плагин оба были копиями поля срабатывания в витрину.
6. **Команды занимают листинг наравне с skills.** Все 110 команд без `disable-model-invocation`; для команд, которые вызывает только человек, это рычаг бюджета (описание уходит из контекста, команда остаётся в меню `/`). Применение меняет поведение (модель перестаёт вызывать команду сама) и ждёт E7 и решения владельца.
7. **Правка описания вместо добавления текста.** Различие даётся заменой слов, суммарная длина `description` в каталоге не растёт; закрытие любой правки - таблица «до/после» (ниже пусто).
