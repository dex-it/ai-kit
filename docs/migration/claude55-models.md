## Решения без прогона (применены в этом PR: правок frontmatter нет)

1. **11 агентов без `model` - узлы трека `dex-auto`.** Это осознанное исключение: модель задаёт скрипт трека (`plugins/auto/dex-auto/tracks/*.js`), а не файл узла ([AGENT_FRAMEWORK.md](../AGENT_FRAMEWORK.md), «Узел трека»). Сверено по скриптам: `coder`, `goal-reader`, `deliverer` - `sonnet`; `debugger`, `designer`, `reviewer` - `opus`; разовые вызовы «снимок правки» и «верификатор» идут на `haiku` + `effort: low` прямо в `node()`.
2. **Находка: у пяти узлов модель не задана и в скрипте** (`corpus-checker`, `onboarder`, `recorder`, `scaffolder`, `skeptic`): они наследуют модель сессии. На Opus-сессии механические `recorder` и `scaffolder` считаются дорого, на дешёвой сессии `skeptic` (фальсификация, открытое суждение) теряет тир. Менять без прогона нельзя (поведение трека): в sweep (ниже) первым пунктом.
3. **`doc-writer: effort: medium` оставлен.** Он равен дефолту 5.5 (`medium`), но дефолт - наследование сессии: на сессии `high` явное `medium` удешевляет, на `medium` ничего не меняет. Снятие изменило бы поведение у пользователей с повышенным effort.
4. **`haiku` не назначается по ощущению.** Условие по политике: узкая шаблонная работа без правок кода и без skills-ловушек; на 5.5 Haiku при `low` в длинном агентном промте чаще останавливается рано ([Effort](https://platform.claude.com/docs/en/build-with-claude/effort), сверено 26.10.2026). Кандидаты для sweep (не решения): `diagram-creator`, `bug-reporter`, `backlog-manager`, `metrics-analyst`, `seq-logging-specialist`.
5. **Алиасы.** `sonnet` и `haiku` ведут на 5.5 только на Anthropic API; у других провайдеров - на 4.x ([model-config](https://code.claude.com/docs/en/model-config), сверено 27.10.2026). Любая замена `sonnet` -> `haiku` вне API даёт Haiku 4.5 без оси `effort`: решение о `haiku` должно учитывать это (валидатор алиас не судит).
6. **`opus` остаётся только там, где в политике названо открытое суждение.** Понижение `opus` -> `sonnet` (кандидаты: `domain-analyst`, `business-requirements-analyst`, `rule-collector`) - только по sweep: пара тир против тира на задачах агента, метрика - стоимость за решённую задачу.

## План sweep (ждёт бюджета, [#88](https://github.com/dex-it/ai-kit/issues/88))

Готовых наборов «агент x задача» в стенде нет (`tests/eval55/experiments`: E1-E10 меряют корневой текст, а не тир агента), поэтому первый шаг - набор.

| Шаг | Что | Оценка |
|---|---|---|
| 1 | Набор E16: по 2 задачи с проверяемым результатом на каждый класс (глубокое суждение, структурная генерация, исполнение по образцу, узкая массовая) - 8-12 агентов-представителей и пять узлов из п. 2; `node tests/eval55/run.mjs controls E16` без модели | 0 USD (подготовка) |
| 2 | `node tests/eval55/run.mjs plan E16 --tiers haiku,sonnet,opus --reps 3` и прогон при `medium`; отклонения `low`/`high` только там, где дефолт ошибается | по `priors.json` (`task`: 0,0024 / 0,049 / 0,098 USD за ячейку Haiku / Sonnet / Opus, Opus экстраполирован): 12 агентов x 2 задачи x 3 тира x 3 повтора = 216 ячеек, около 11-15 USD; при реальных (длинных) задачах агентов в 2-3 раза больше |
| 3 | Решение по таблице «агент, было, стало, основание»; правки frontmatter и `node(...)` в треках, patch-версии плагинов | 0 USD |

Шаг 2 - единственное платное; решение остаётся за владельцем после просмотра шага 1.
