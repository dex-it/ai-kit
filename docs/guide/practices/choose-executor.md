Каждый вид нужен для своего. Выбор неверного вида не ломает работу сразу: он делает её дороже, хрупче или нестабильнее. Страница даёт способ выбрать по свойствам вида, а не по привычке. Устройство каждого вида разобрано в разделе [Разработка плагинов](/authoring/), здесь - выбор.

## Свойства видов

| Вид | Кто запускает | Где работает | Что делает | Цена |
|---|---|---|---|---|
| **Skill** | модель сама по описанию, либо явный вызов | в контексте того, кто его вызвал | подкладывает знания и ловушки | описание в листинге на каждом ходу; тело при вызове |
| **Агент** (специалист) | команда или модель по описанию | в своём контексте | выполняет роль по фазам, возвращает статус и поля | описание в листинге; тело и предзагрузка при запуске |
| **Команда** | вы, явным вызовом | в вашей сессии | ведёт порядок шагов, держит остановки на вашем решении | описание в листинге; тело при вызове |
| **Хук-команда** | событие клиента | в процессе оболочки | скрипт на событие, текст или блок | не читается моделью |
| **Мод** | событие клиента | в процессе Claude Code | панели, строки, перехват, своё состояние | не читается; ошибка валит сессию |
| **CLI-утилита** | вы или модель через команду | в оболочке | одна программа, read-only диагностика | команды в листинге |
| **MCP-сервер** | модель, как инструмент | отдельный процесс | структурированные инструменты по системе | схемы инструментов и секреты |
| **Файл правил** (`CLAUDE.md`) | клиент при старте | в каждом контексте | постоянные договорённости | читается каждый раз целиком |

## Решение по вопросам

1. **Нужно ли это вообще модели?** Если речь о том, что Claude Code делает или показывает (панель, строка статуса, запрет вызова) - не модель, а клиент: хук или мод. Всё остальное - текст для модели.
2. **Нужно ли это всегда или только в задаче?** Всегда и для всех агентов проекта - `CLAUDE.md` (коротко: только невыводимое). В задаче по теме - skill. Только когда вы позвали - команда.
3. **Это знание или работа?** Знание («на что наступают в Kafka») - skill. Работа с фазами, результатом и проверкой («проведи ревью MR») - агент.
4. **Нужен ли свой контекст?** Если работа читает много кода и нужен сжатый возврат, чтобы не засорять сессию, - агент. Если делается в паре вызовов инструментов - команда или сама сессия.
5. **Кто разговаривает с человеком?** Только главный поток. Поэтому порядок работы с остановками на вашем решении - команда-вход, а агент возвращает ей нехватку.
6. **Внешняя система: CLI или MCP?** Для чтения («покажи поды», «объясни запрос») берите CLI-утилиту: нет сервера, меньше радиус поражения, используется уже настроенная авторизация. MCP оправдан для длинного автономного сценария, записи в систему через Claude (с чёткой границей авторизации) и общего доступа нескольких агентов ([MCP-конфигурации](/authoring/mcp/)).

## Почему не «всё в одно»

- **Skill с процедурой** превращается в плохого агента: у него нет фаз, нет критерия завершения, нет статуса. Валидатор остановит разрастание (больше 250 строк), но проблема раньше - смешение знания и работы.
- **Агент вместо команды.** Вызов человеком с остановками на вашем решении агент не обеспечивает: вопросы из агента к вам не доходят, а возвращаются вызывающему. Агент без команды-входа хорошо подходит там, где его вызывает другой узел.
- **Команда вместо агента.** Команда в вашей контексте читает и засоряет его. Всё, что требует нескольких фаз с гейтами, - агент (признаки в [Писать команду](/authoring/command/)).
- **Мод вместо хука.** API модов нестабилен, ошибка валит сессию. Берите мод, когда нужен интерфейс или перехват с состоянием.
- **MCP вместо CLI.** Лишний сервер, лишняя поверхность секретов, больше схем инструментов в контексте.

## Как виды связываются

Композиция в Claude Code устроена так, что у неё есть неочевидные границы:

- **Skill не загружает другой skill сам.** Упоминание `dex-skill-X` в теле не запускает его. Надёжно только явное предписание: «вызови `Skill` с именем `{plugin}:{skill}`». Формулировка «загружает» без слов «предписывает» или «вызывает `Skill`» вводит в заблуждение, и норма требует её переписать.
- **Связь между специалистами в бандле - это установка вместе**, а не вызов в рантайме.
- **Команда вызывает агентов** (`Agent`), агент загружает skills (`Skill`). Сам skill ничего не запускает: его текст читает и исполняет тот, кто его вызвал.
- **Оркестрация - у главного потока, исполнение - в агенте.** Оркестратор раздаёт работы разным ролям и может остановиться на вас, поэтому его носитель - команда (дефолт каталога) или process-skill, который исполняет главный поток. Субагентом оркестратор быть не может: у спавненного агента нет канала к человеку. Параллельные проходы одного типа внутри своей работы (фокусы ревью, оси приёмки) оркестрацией не считаются, это дробление собственной работы агента ([SKILL_FRAMEWORK.md](https://github.com/dex-it/ai-kit/blob/main/docs/SKILL_FRAMEWORK.md#норма-каталога-оркестрация---у-главного-потока-исполнение---в-агенте)).

Нормативный свод - [AGENTS.md, «Механизмы композиции в Claude Code»](https://github.com/dex-it/ai-kit/blob/main/AGENTS.md#механизмы-композиции-в-claude-code) и справка [EXTENSION_MECHANISMS.md](https://github.com/dex-it/ai-kit/blob/main/docs/EXTENSION_MECHANISMS.md) (сравнение хука, мода и Agent SDK).

## Признаки неверного выбора

| Симптом | Вероятная ошибка |
|---|---|
| skill разрастается, в нём появляются «шаг 1, шаг 2» | это агент или команда |
| агент «просит» уточнений, которые до вас не доходят | вопрос должен задавать вызывающая команда; агент должен вернуть `blocked` |
| команда на 200+ строк с несколькими сценариями | агент |
| мод, который только печатает текст на событие | хук-команда достаточно |
| MCP-сервер ради чтения из базы | CLI-утилита |
| правило повторяется в `CLAUDE.md`, в skill и в агенте | один дом: оставить одно место и ссылаться |

## Если вы выбираете для своей задачи

1. Опишите задачу одной фразой с глаголом: «знает ловушки X» (skill), «проводит Y» (агент), «запускается мной для Z» (команда), «показывает W в интерфейсе» (мод).
2. Проверьте по списку вопросов выше.
3. Если в каталоге уже есть подходящий плагин, начните с него: [Карта каталога](/architecture/levels/), [Что поставить](/start/choose/).
