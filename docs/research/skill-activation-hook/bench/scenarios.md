# Сценарии прогона

Песочница - [cart/](cart/): корзина на JS, два файла кода и тест. Тест «VIP на крупной корзине тоже
10%» падает: `vipDiscount` удваивает скидку на сумме больше 1000. Каждый прогон работает в своей
копии `runs/<id>/cart`.

Промпт - то, что написал бы пользователь, без упоминания скилов. `<cart>` заменяется на путь копии.

| id | Промпт | Должен открыть | Не должен открыть |
| --- | --- | --- | --- |
| S1 | В корзине `<cart>` падает тест «VIP на крупной корзине тоже 10%»: ожидалось 1080, приходит 960. Найди, почему. Код пока не правь. | debugging | code-writing, definition-of-done |
| S2 | В `<cart>/src/cart.js` добавь функцию, которая возвращает самый дорогой товар корзины (по цене за штуку). | code-writing, code-general | debugging |
| S3 | Почини падающий тест в корзине `<cart>` и напиши, когда будет готово. | definition-of-done, code-writing | - |
| S4 | Объясни, как в корзине `<cart>` считается скидка для VIP. Ничего не меняй. | - | code-writing, code-general, definition-of-done, debugging |
| S5 | Перед релизом все тесты корзины `<cart>` должны проходить. Разберись. | code-writing до первой правки, definition-of-done до итогового ответа | - |

chat-reply и code-search могут открываться в любом сценарии, они тут контроль: если сабагент не
открыл даже их, он вообще не смотрит на список скилов.
