# Хук-напоминание и варианты описаний, Sonnet, 17.11

Стенд - `claude -p` на Sonnet, Claude Code 2.1.326, набор из 14 скилов автора, песочница
[cart/](../cart/). Серия - S1-S4 по 3 прогона (`scripts/run_series.sh`). Хук -
`scripts/skill_eval_hook.py` на `UserPromptSubmit` (`SETTINGS=scripts/hook-settings.json`): пройти по
списку скилов и открыть подходящие до чтения и правок. Текст не зависит от набора скилов.

В ячейках - в скольких прогонах из 3 открыт нужный скил.
